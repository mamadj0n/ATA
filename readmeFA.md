# ATA (دستیار ترمینالی هوش مصنوعی)

**ATA** یک ابزار سبُک، بدون وابستگی (Zero-Dependency) و کاملاً محلی برای خط فرمان است که دستورات زبان طبیعی شما را از طریق مدل‌های زبانی محلی (در بستر Ollama) به دستورات اجرایی لینوکس تبدیل می‌کند.

این ابزار مانند یک پل میان ترمینال و هوش مصنوعی عمل می‌کند تا شما را از حفظ کردن دستورات پیچیده و طولانی لینوکس بی‌نیاز کند؛ آن هم در حالی که ترمینال شما کاملاً ایمن و آفلاین باقی می‌ماند.

---

## ویژگی‌های اصلی

* **بدون وابستگی به کتابخانه‌های جانبی:** تماماً با استفاده از کتابخانه‌های استاندارد پایتون (`urllib` ،`subprocess` ،`readline`) ساخته شده است؛ بدون نیاز به `pip install`.
* **حفظ حریم خصوصی و عملکرد آفلاین:** اجرا به‌صورت محلی روی Ollama با استفاده از مدل `qwen2.5-coder:1.5b`. بدون نیاز به API Key، بدون پیش‌آمدن تاخیرهای ابری و بدون ردگیری اطلاعات.
* **اجرای تعاملی:** پیش‌نمایش دستورات تولید شده قبل از اجرا. قابلیت تایید، لغو یا حتی ویرایش آنی دستور پیشنهادی.
* **امنیت تعبیه‌شده:** پاک‌سازی خودکار علامت‌های اضافی (مانند بک‌تیک‌های markdown) و شناساگر دستورات مخرب سیستم‌عامل (مانند `rm -rf /`).

---

## پیش‌نیازها

۱. **نصب Ollama:** مطمئن شوید که Ollama روی سیستم شما نصب و در حال اجرا است:

```bash
curl -fsSL https://ollama.com/install.sh | sh

```

۲. **دریافت مدل محلی:** مدل پیشنهادی مخصوص کدنویسی را دریافت کنید:

```bash
ollama pull qwen2.5-coder:1.5b

```

---

## مراحل نصب

۱. **کلون کردن مخزن پروژه:**

```bash
git clone https://github.com/your-username/ATA.git
cd ATA

```

۲. **اعطای دسترسی اجرایی به اسکریپت:**

```bash
chmod +x main.py

```

۳. **نصب سراسری در سیستم (با نام `ata`):**

```bash
sudo cp main.py /usr/local/bin/ata

```

## نحوه استفاده

کافیست دستور `ata` را همراه با درخواست خود به زبان انگلیسی یا فارسی بنویسید:

```bash
ata "whats my cpu"

```

یا:

```bash
ata "مشخصات پردازنده من چیه"

```

### منوی گزینه‌ها

پس از پیشنهاد دستور توسط هوش مصنوعی، منوی زیر نمایش داده می‌شود:

```text
💡 Suggested Command:
  lscpu

Options: [y] Execute | [n] Cancel | [e] Edit
What to do? (y/N/e):

```

* **کلید `y` (بله):** دستور را مستقیماً در ترمینال شما اجرا می‌کند.
* **کلید `n` (خیر / پیش‌فرض):** اجرای دستور را لغو می‌کند.
* **کلید `e` (ویرایش):** دستور پیشنهادی را وارد پرامپت تعاملی می‌کند تا بتوانید پارامترهای آن را قبل از اجرا تغییر دهید.

## نمونه کاربردها

**یافتن فایل‌های بزرگ در پوشه خانگی:**

```bash
ata "find files larger than 100MB in home directory"

```

**بررسی پورت‌های فعال شبکه:**

```bash
ata "show listening ports and associated processes"

```

---

## شخصی‌سازی

برای تغییر مدل هوش مصنوعی در یک دستور خاص، از پرچم `m-` یا `model--` استفاده کنید:

```bash
ata "compress images in current directory" -m llama3.2:1b

```

همچنین می‌توانید مقدار متغیر `DEFAULT_MODEL` را داخل فایل `/usr/local/bin/ata` تغییر دهید تا مدل محلی دلخواه شما به عنوان پیش‌فرض تنظیم شود.

---

## امنیت و ایمنی

* پروژه ATA دارای یک سیستم بازرسی است که اگر دستوری با الگوهای خطرناک سیستم‌عامل (مانند `rm -rf /` یا `mkfs` یا نوشتن مستقیم روی دیسک) مطابقت داشته باشد، هشدار جدی نشان می‌دهد.
* هیچ دستوری بدون تایید مستقیم و صریح کاربر (`y` یا `e`) اجرا نخواهد شد.
